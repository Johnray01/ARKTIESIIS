# Aggressive Three-Week Target

## Week 1
- Foundation and database.
- Authentication.
- Email 2FA.
- Role access.
- Admin account management.
- Student master list and basic student CRUD.

## Week 2
- Enrollment/academic history.
- Subjects and grades.
- Finance records.
- Document upload.
- Local Tesseract OCR and Poppler PDF integration.
- Validation rules and result states.

## Week 3
- Complete dashboards.
- Audit logs.
- Security review.
- Full testing and bug fixing.
- UI polish.
- Demo data, backup, and deployment/defense preparation.

Rule: do not add features outside the approved thesis scope until all required features work end to end.
